# Technology World for Android

This project packages the Technology World website as an Android app.

## Get the APK from GitHub

1. Create a GitHub repository and upload this folder's contents.
2. Open the **Actions** tab, choose **Build Android APK**, then select **Run workflow**.
3. When the run finishes, download `technology-world-apk` from the run page.

The download contains `app-debug.apk`, ready to install on Android after allowing installs from the chosen browser or file manager.

For Google Play, create a signed release APK or AAB with your own signing key.
